# Pagoda Sammler

Fabric-Mod für Minecraft 26.2 zum Pagoda-Tutorial von Cortezerino.

- Benenne eine Shulker-Kiste im Amboss in **Pagoda** um und trag sie im Inventar.
- Alles, was du aufsammelst und was für die Pagoda noch fehlt, landet direkt in dieser Kiste.
- Ist eine Kiste voll, geht es in die nächste Pagoda-Kiste. Mehr als gebraucht wird nicht eingepackt.
- `/pagoda` zeigt im Chat, was noch fehlt (gezählt werden Inventar, Endertruhe und alle Shulker-Kisten darin).

**Download:** unter *Releases* → `pagoda-mod-26.2.jar` in den `mods`-Ordner legen. Fabric Loader und Fabric API werden gebraucht.
